# Introduction to Scientific Python

Python is a free, open-source programming language that has become an important tool in scientific research. Its strength comes not only from the language itself, but also from an extensive ecosystem of packages that allow researchers to analyze data, perform calculations, create visualizations, and interact with scientific instruments. Python supports object-oriented programming, allowing data and associated operations to be organized into reusable objects.

One of Python's greatest strengths is its extensive collection of packages that extend the capabilities of the language. A package is a collection of related Python modules that provide specialized functionality, such as performing mathematical calculations, analyzing experimental data, generating graphs, or even reading data from a sensor.

Thousands of packages are available through repositories such as the Python Package Index (PyPI) and conda-forge. Together, these packages form an ecosystem that allows scientists to build upon tools developed by other researchers rather than writing everything from scratch.

Because different projects may require different packages or versions of packages, we will learn to create virtual environments. An environment provides an isolated collection of Python packages and dependencies for a particular project, helping prevent conflicts and making scientific workflows more reproducible.

This course is divided into three core modules.

**Module 1: Setting Up Your Computer.** We will install Python and the tools needed to develop scientific programs, create virtual environments, and learn to use JupyterLab. The course will be taught through Jupyter notebooks, which combine executable code, explanatory text, equations, and visualizations in a single interactive document. We will also introduce Git and GitHub, which allow us to track changes to our code, share notebooks, collaborate with others, and maintain a record of our scientific work.

**Module 2: Python Programming Fundamentals.** We will learn the basic elements of Python programming, including variables, data structures, control flow, functions, and working with objects. Because students enter this course with different levels of programming experience, we will also introduce AI-assisted coding using Notebook Intelligence within JupyterLab. AI tools can help us generate, explain, debug, and modify code, allowing us to focus more attention on scientific questions. However, an essential part of scientific programming is learning to evaluate AI-generated code, understand what it does, and verify that its results are scientifically meaningful.

**Module 3: Scientific Computing with Python.** Python has an extensive ecosystem of scientific packages. Some, such as NumPy, pandas, Matplotlib, and SciPy, provide fundamental tools for numerical calculations, data analysis, and visualization that are useful across virtually all scientific disciplines. Others are developed to address specialized problems in fields such as chemistry, biology, physics, and geology. As a class, we will explore the core scientific Python ecosystem before branching into individual projects where students discover and apply discipline-specific packages to scientific problems of their own interest. These projects will include creating customized Python environments and sharing their work through GitHub repositories.
